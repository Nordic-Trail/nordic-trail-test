# Experimental OSM–NVDB matching, 25 November 2026
14 synthetic geometry cases in planar metres; no real NVDB or OSM geometry, no network calls, no planner changes. Thresholds are illustrative, not calibrated. Multiple candidates, incomplete coverage, missing identifiers and split segments abstain. Even a single geometry candidate remains unconfirmed; network type is only displayed as source evidence. Next step: import Vägtrafiknät geometry and reference link identifiers and date validity, transform coordinates into a common metric CRS, validate against real parallel links, topology, direction, grade separation, split segments and source updates. Within NVDB, Element ID + Measure From/To + validity can relate products; OSM IDs are not NVDB IDs. Do not use this prototype for travel or legal decisions.
